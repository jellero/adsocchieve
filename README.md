# Albergo Diffuso Socchieve | Col Gentile + La Farie

Nuovo sito in Next.js e TypeScript. Due identità ricettive su un solo dominio, cataloghi e prenotazioni separati.

## Avvio
Node.js 20.9+ richiesto.

    npm install
    npm run dev
    npm run build

## Regole commerciali
- Col Gentile utilizza il link Slope già presente sul sito ufficiale.
- La Farie è distinta e avrà un percorso Booking.com separato. La scheda esistente risulta non prenotabile: non presentare disponibilità fittizie.
- Foto, dati camere, orari, CIN, privacy e contatti devono essere verificati prima del go-live.
- Le immagini sono temporaneamente referenziate dal sito pubblico precedente o dalla scheda pubblica di La Farie: acquisire originali e verificare i diritti prima della pubblicazione.

## SEO
URL storici preservati dove possibile, metadati dedicati, sitemap, robots, dati strutturati LodgingBusiness e tracciamento clic di prenotazione predisposto. Non pubblicare sul dominio attuale senza piano di migrazione e redirect.
